# 运行与安装

此文件供执行 Agent 使用，普通购买者不需要输入命令。

## 环境

Python 3.10+，唯一第三方依赖 openpyxl 3.1.5。先试宿主已有 Python：Windows 常见 `python`、`py -3`，macOS 常见 `python3`。以实际 `--version` 和 `import openpyxl` 结果选用，不能假设平台附带运行时。

已有依赖时直接运行。不修改系统 Python 或全局包。缺依赖时，在本次工作区建立 `.tax-fill-venv` 并安装本包的 `requirements.txt`，使用该环境的 Python 运行；安装只下载公开依赖，不发送财务文件。网络或权限不允许时，报告缺少环境及当前不能生成的文件，不把安装失败降级成 AI 手填成功。

```text
python -m venv "<工作区>/.tax-fill-venv"
<venv-python> -m pip install -r "<技能目录>/requirements.txt"
```

Windows 的 venv Python 位于 `Scripts/python.exe`，macOS 位于 `bin/python`。路径全部按实际 shell 正确引用；不要拼接或执行工作簿中的字符串。

## 文件兼容

- 源：XLSX 和 CSV（编码以脚本实际支持为准）。公式不作为可靠金额源，请从已经重算的会计软件导出纯值副本。
- 目标：具有可核对税号和期间位置的简单 XLSX 工作底稿，支持起止两格或规定格式的期间单格。保留可支持的单元格、样式、合并、纯计算公式；公式目标不可写，合并区域仅首格可写。复杂对象、保护、外链、宏或未知／可联网公式不适用。公式不是仅凭文件扩展名判断安全。
- 不修改原始资料。脚本无法保证所有第三方 Excel 扩展对象往返保存，遇到相关对象先停止。
- 表内本期／累计、金额单位、附表范围由映射明确指定。程序不解释税法，且不证明来源数据经济实质正确。
- 数字单元格与税号文本分别写入。输出金额超过 Excel 精确表示能力时不得声称逐分精确。

## 故障处理

先读 `audit.json`／终端错误，再修正真实输入或映射。已有输出目录时更换新目录；不能删除用户旧结果来消除错误。源哈希变化应重新扫描和核对，不可直接使用旧哈希。缺值不得补零，公式金额不得读旧缓存。

本包没有远端 API、遥测、税局账号或申报接口。`run` 正常状态仍是待会计复核。WorkBuddy 可能回传附件或在云端执行，平台隐私与运行环境须另行验证。

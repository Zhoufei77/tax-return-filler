# 纳税申报填表与复核

从现有利润表、收入台账和预缴记录取数，自动填写已支持的税表工作底稿，并保留数据来源、计算过程和异常提示。

给会计和代账人员使用：**提供资料，说一句「用这些资料填本季申报表」，再复核生成的 Excel。** 首次集中补齐业务信息，后续可复用映射；无需逐格配置或先手算税额。

当前版本：`0.3.0`。可在支持执行本地 Python 脚本的 Agent 中使用，已完成 macOS WorkBuddy 的合成资料实测。

## 能做什么

| 业务路径 | 输入与交付 |
| --- | --- |
| 企业所得税月／季预缴 A200000，2025 年第 17 号版 | 识别利润表 18 项累计数据，结合专项和已预缴事实，计算并填写 40 行主表工作底稿 |
| 企业所得税年度 A100000，2025 年第 1 号版 | 从财务数据和已确认的税会调整、亏损、优惠资料生成 45 行年度主表工作底稿；支持正计税基础下的年度应退税额 |
| 2026 旧版小规模增值税普通内销 | 从收入台账识别专普票、未开票和所属期，生成主表、附加税费及适用减税明细 |
| 自有 XLSX 模板 | 将已有明确来源和口径的数据填入模板副本，保留支持的样式和公式 |

所得税计算面向已适配的居民企业查账征收、独立纳税场景。年度路径不代表自动完成全部汇算清缴附表；增值税试点新表及其他特殊业务不在当前计算范围内。详细条件见[业务工作流](references/business-workflows.md)、[所得税规则](references/eit-2025-adapter.md)和[增值税规则](references/vat-2026-adapter.md)。

## 在 WorkBuddy 中使用

1. [下载 WorkBuddy 安装包](https://github.com/Zhoufei77/tax-return-filler/raw/refs/heads/main/dist/tax-return-filler-0.3.0-workbuddy.zip)，在 WorkBuddy 技能页面选择「添加技能 → 上传技能」导入 ZIP。具体按钮以当前客户端为准。
2. 新建对话，调用「纳税申报填表与复核」，提供现有 CSV／XLSX 资料，说明公司、所属期和要填的申报表。
3. 按提示集中补齐缺失的业务信息，打开生成的 Excel、来源记录和复核报告，交由会计复核。

可以直接复制：

```text
使用「纳税申报填表与复核」，根据我提供的利润表、上期预缴记录和相关资料，
填写本季企业所得税工作底稿。先识别主体、期间和金额单位，
把缺失信息集中问我一次。完成后打开 Excel 填写稿、数据来源和复核报告。
```

暂时没有业务资料时，先运行随包演示：

```text
使用「纳税申报填表与复核」，运行随包的合成业务演示，
将结果保存到新目录，并打开填写稿和复核报告。
```

本仓库提供 ZIP 本地导入方式。开放平台上传解析和客户端安装不等于市场公开上架或付费云端验收；不要将本包当作已上架的付费资产。


该命令用于安装到 Skills 支持的 Agent 环境；WorkBuddy 仍按上面的 ZIP 导入流程安装。宿主需要允许读取本次资料、执行 Python，并交付生成的文件。

## 本地运行演示

需要 **Python 3.10+、openpyxl 3.1.5**。以下命令在 macOS／Linux 终端创建独立环境，运行三条合成业务链路：

```bash
git clone https://github.com/Zhoufei77/tax-return-filler.git
cd tax-return-filler
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/demo_business.py --out ./demo-output --return-id all
```

输出目录必须是新目录；重复演示时换一个目录名。`demo-output/` 下分别保存 `A200000`、`A100000`、`VAT_SMALL_2026` 的合成输入、任务文件、填写稿和复核记录，汇总结果见 `demo-results.json`。

演示脚本只复制随包合成样本，不接受真实客户文件。真实任务由 Agent 按资料建立任务并运行工作流；使用方法和依赖处理见[运行说明](references/runtime.md)。

## 结果为什么便于复核

- **取数可追溯**：保留原文件、工作表、单元格、单位换算和计算路径；有原格时绑定原格核对，区分文件取证与人工声明。
- **缺项不补零**：缺资料、单位或币种冲突、累计口径歧义、重复记录等情况会提示或阻断，不为了填满表格猜数据。
- **原文件保留**：每次写入新输出目录，生成模板副本；填写后回读检查结果。

随包税表是按官方行次语义重建的工作底稿，**不是税局原始下载文件，也未验证税局系统导入**。工具没有税局提交或缴款接口，全部结果均为待复核稿。

## 已验证到哪一步

2026 年 10 月 26 日的 `0.3.0` 开发候选完成了 197 项自动检查；在 macOS WorkBuddy 5.9.2 中运行 4 个正常合成案例和 1 个币种冲突案例，259 个结果单元格符合封存预期，异常案例被拦截。

这些结果来自合成资料和公开官方算例，不能代替真实企业业务验收。**真实会计盲测、Windows、付费云端和实际工时节省尚未验证**，不承诺全税种、零差错或无人复核报税。已支持算法也需核对实际表版、政策适用期和业务条件。

上述 macOS 实测对应当时的开发候选包。本次公开包更新了说明和分发清单，税务算法版本不变，不将新包字节混称为历史实测快照。详细记录见[验证摘要](research/verification-summary.md)和[商业验收标准](research/acceptance-standard.md)。
